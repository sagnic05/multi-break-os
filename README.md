## ✨ Overview
Multi-Break OS serves as a centralized platform containing various unique web experiences. It features a dedicated hub UI that seamlessly navigates between different applications, fully optimized with a compact layout for different screen sizes.

### 🕹️ Included Modules & Games
* **Arcade** (`arcade.html`)
* **RPG** (`rpg.html`)
* **Maze** (`maze.html`)
* **Escape** (`escape.html`)
* **Match** (`match.html`)
* **Crush** (`crush.html`)
* **Heap** (`heap.html`)
* **Sorter** (`sorter.html`)
* **Assembler** (`assembler.html`)

## 🛠️ Tech Stack
This project is built entirely with vanilla web technologies, ensuring lightweight performance and quick load times directly in the browser:
* **HTML5:** Semantic structure for the OS hub and individual game modules.
* **CSS3:** Custom styling featuring responsive design for compact screens.
* **JavaScript (ES6+):** Core game logic, UI interactions, and a dedicated `audio-manager.js` for handling sound effects.
